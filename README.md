# ГрафМастер СПО 🎓
### Веб-платформа для составления вариантов по графикам функций с живой анимацией и подробным пошаговым разбором решений (1 курс колледжа)

Современное веб-приложение для преподавателей математики учреждений СПО (среднего профессионального образования), позволяющее быстро составлять сбалансированные варианты проверочных, контрольных и практических работ по теме **«Графики и свойства функций»** с интерактивными анимированными графиками и полными методическими решениями.

---

## 🌟 Ключевые возможности

1. **✨ Живые плавные анимации**:
   - **Анимация вычерчивания кривой (Draw Path Animation)**: при открытии карточки или разбора график функции плавно вычерчивается в реальном времени слева направо.
   - **Пульсирующие ключевые точки**: нули функции, вершина параболы, экстремумы и точки пересечения подсвечиваются мягкими пульсирующими кольцами.
   - **Динамическая анимация параметров в лаборатории**: кнопка «▶ Запустить анимацию параметра» плавно деформирует, растягивает или колеблет график с частотой 60 fps (демонстрация коэффициентов $a, k, \omega$).
   - **Интерактивная подсветка этапов**: кнопки «Нули функции», «Вершина / Экстремум», «Знакопостоянство» динамически подсвечивают нужные элементы прямо на графике.

2. **🔍 Подробный пошаговый разбор решений (кнопка на каждом задании)**:
   - **Теоретическая база и формулы**: правила и теоремы, необходимые для решения конкретной задачи.
   - **Пошаговые выкладки**: Шаг 1, Шаг 2, Шаг 3 с математическими расчетами и обоснованием.
   - **Интерактивный чертеж с подсветкой**: клик по любому шагу подсвечивает соответствующую область на чертеже.
   - **Типичные ошибки первокурсников**: на чем чаще всего теряют баллы студенты 1 курса.
   - **Критерии оценивания (ФГОС СПО)**: детальная разбалловка за каждый пункт ответа.

3. **🎯 Конструктор вариантов**:
   - Автоматическая синхронная генерация от **1 до 4 параллельных вариантов** (одинаковый уровень сложности, уникальные формулы, числовые данные и чертежи).
   - Быстрые шаблоны: Самостоятельная (20 мин), Контрольная (45 мин), Диагностический срез (60 мин), Зачет (90 мин).
   - Настройка шапки работы: название колледжа, группа, дисциплина, шкала оценивания.

4. **📚 Исчерпывающий банк заданий СПО (все 18 видов графиков функций)**:
   - **Линейная функция** ($y = kx + b$, угол наклона, угловой коэффициент, пересечения с осями).
   - **Квадратичная парабола** ($y = ax^2 + bx + c$, вершина, ось симметрии, нули, направление ветвей).
   - **Дробно-линейная гипербола** ($y = \frac{k}{x - x_0} + y_0$, вертикальная и горизонтальная асимптоты).
   - **Кубическая парабола** ($y = ax^3$, нечетность, симметрия относительно начала координат, точка перегиба).
   - **Степенная функция четной степени** ($y = ax^4 + c$, уплощение дна, крутизна роста).
   - **Квадратный корень** ($y = a\sqrt{x - x_0} + y_0$, ОДЗ $x \ge x_0$, начальная точка, монотонность).
   - **Кубический корень** ($y = \sqrt[3]{x}$, область определения вся прямая $R$, нечетность, S-образная кривая).
   - **Функция с модулем** ($y = a|x - x_0| + y_0$, вершина излома, число корней уравнения с параметром $f(x) = m$).
   - **Модуль квадратичной параболы** ($y = |x^2 - 4|$, W-образная кривая, отражение отрицательной части).
   - **Показательная функция роста** ($y = a^x$, $a > 1$, экспоненциальный рост, асимптота $y = 0$).
   - **Показательная функция затухания** ($y = (1/a)^x$, $0 < a < 1$, экспоненциальное убывание).
   - **Логарифмическая функция** ($y = \log_a x$, $\ln x$, ОДЗ $x > 0$, вертикальная асимптота $x = 0$, нуль).
   - **Тригонометрия: Синусоида и гармоники** ($y = A\sin(\omega x)$, амплитуда $A$, период $T = \frac{2\pi}{\omega}$).
   - **Тригонометрия: Косинусоида** ($y = A\cos x + b$, четность $\cos(-x) = \cos x$, экстремумы).
   - **Тригонометрия: Тангенсоида** ($y = \tan x$, период $\pi$, вертикальные асимптоты $x = \pm\frac{\pi}{2}$).
   - **Обратные тригонометрические** ($y = \arctan x$, горизонтальные асимптоты $y = \pm\frac{\pi}{2}$).
   - **Кусочно-заданные функции** (различные формулы на интервалах, точки стыка, исследование непрерывности).
   - **Графическое решение уравнений** ($f(x) = g(x)$, пересечение параболы и прямой, корни).
   - **Комплексное исследование свойств** ($D(f)$, $E(f)$, нули, знаки, монотонность, экстремумы, max/min на отрезке).

5. **📱 Полная мобильная адаптивность и нативный экранный режим**:
   - Работает на смартфонах (iOS, Android), планшетах и компьютерах: плавный горизонтальный touch-скролл вкладок, адаптивные карточки и масштабируемые SVG-графики.
   - Варианты генерируются прямо в интерфейсе сайта в неоновом стиле (переключение между вариантами кнопками `[Вариант 1]`, `[Вариант 2]`, `[Вариант 3]...`).
   - Интерактивная экранная панель **«Ключи и решения ко всем вариантам»** для преподавателя прямо в конструкторе.
   - Печать на бумагу А4 доступна в любой момент отдельной кнопкой.
