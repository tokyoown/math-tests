# NEOMATH ⚡
### Интерактивная платформа математики с генератором вариантов, банком 5 000 задач и интерактивной доской

Современное веб-приложение для составления сбалансированных вариантов проверочных, контрольных и практических работ по математике (25 модулей: алгебра, тригонометрия, анализ, геометрия, стереометрия, векторы, теория вероятностей, комплексные числа). Включает интерактивную доску для вычислений и чертежей, экранную математическую клавиатуру и систему автоматической проверки ответов студентов.

---

## 🌟 Ключевые возможности

1. **⚡ Конструктор вариантов**:
   - Выбор количества заданий: от **1 до 25** (по одной задаче каждого тематического раздела).
   - Автоматическая балансировка сложности и расчет итоговых баллов.
   - Поддержка многовариантности (до 4 параллельных вариантов с уникальными числовыми значениями).

2. **📚 Банк 5 000 задач (25 модулей)**:
   - 25 тематических модулей по 200 задач в каждом.
   - Мгновенный поиск по теме, формуле или тексту задания.
   - Фильтрация по уровням сложности (базовый, средний, повышенный).
   - Наглядные карточки заданий с примерами и эталонными ответами.

3. **⌨️ Экранная математическая клавиатура**:
   - Полный набор математических символов: производные (`f′(`, `′`, `f′(x) = `), интегралы (`F(x) = `, `dx`), степени и корни (`x²`, `x³`, `xⁿ`, `√`, `∛`), тригонометрия (`sin`, `cos`, `tg`, `ctg`, `π`), векторы, комплексные числа (`|z|² = `, `i`) и др.
   - Интеллектуальная нормализация ввода: распознавание как полных формул, так и числовых ответов.

4. **🎨 Интерактивная доска для черчения**:
   - Неоновое перо, прямые линии, точки с координатами $(x; y)$, текст и ластик.
   - Адаптивный холст с поддержкой сенсорных экранов и стилусов (Pointer Events).
   - Автоматическая привязка к условию текущего варианта задания.

5. **📱 Полная мобильная адаптивность**:
   - Идеальное отображение на смартфонах, планшетах и мониторах высокого разрешения.
   - Удобные тач-зоны и адаптивное позиционирование элементов интерфейса.

## 🚀 Быстрый запуск

Проект работает прямо в браузере и не требует сборки или установки Node.js / Python:

1. Склонируйте или скачайте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_АККАУНТ/neomath.git
   ```
2. Откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari).
3. Или запустите локальный сервер двойным кликом по `start_local_server.bat` / `start_site.bat`.
